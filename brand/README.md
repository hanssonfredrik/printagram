# Inbunden logo

A closed hardcover book (spine on the left, page edges on the right) with a serif "I" in Lora on the cover, on the brand blue `#4A5FA8`. Paper `#FAF7F2`, spine `#DCD2C0`, page edges `#E6DECF`.

| File | Use |
| --- | --- |
| `inbunden-logo-square-120.png` | Google OAuth consent screen logo (square, 120 × 120, no transparent corners) |
| `inbunden-logo-square-512.png` | Anywhere a square logo is asked for (Meta app icon, Stripe, social profiles) |
| `inbunden-logo-120.png`, `-512.png` | Rounded-corner app-icon style, transparent corners |
| `inbunden-monogram-*` | Alternative: a large serif "I" alone, matching the favicon |
| `*.svg` | Vector sources. The "I" uses the Lora font; without it installed, viewers fall back to Georgia. Use the PNGs when the exact look matters. |
